# 🎈 위례키즈 도서관 (Wirye Kids Library)

> 송파구, 하남 위례, 성남 위례 도서관의 유치원/어린이 체험 프로그램을 일괄 수집하고, 예약 오픈 알림 및 원클릭 자동완성 북마클릿을 제공하는 로컬 웹앱

---

## 1. 프로젝트 배경 및 문제 정의

위례신도시는 서울 송파구, 경기 하남시, 경기 성남시 3개 행정구역이 결합된 생활권입니다. 
주민들은 행정구역에 상관없이 인근 도서관을 모두 이용하지만, 각 지자체별 도서관 시스템이 완전히 분리되어 있어 부모들이 자녀(유치원 및 미취학 아동)의 문화/체험 프로그램을 신청하려면 세 지자체 사이트를 일일이 들어가서 수강신청 일정을 확인해야 했습니다.

**위례키즈 도서관**은 이 세 권역 도서관의 프로그램을 자동으로 수집/정규화하여 한곳에서 확인하고, 신청 당일 폼 입력을 0.1초 만에 마칠 수 있도록 돕습니다.

---

## 2. 주요 기능

- **통합 큐레이션 및 연령별 필터링**:
  - 🎈 **유치원/유아 (4~7세)** 전용 집중 필터 (기본 추천 뷰)
  - 🍼 영아 (0~3세, 북스타트)
  - 🎒 초등 저학년 (1~3학년)
  - 👨‍👩‍👧 가족/보호자 동반
- **접수 상태 및 일정 실시간 확인**:
  - ⚡ **접수중 (즉시 신청 가능)**
  - ⏰ **접수예정 (오픈 대기)**
  - ⏳ **대기접수 / 마감**
- **⚡ 위례키즈 예약 부스터 (북마클릿)**:
  - 자녀 정보(이름, 생년월일, 성별, 보호자 연락처)를 사전 등록하면 브라우저 북마클릿 자동 생성
  - 예약 당일 도서관 신청 폼이 열렸을 때 북마클릿 클릭 한 번으로 모든 입력 필드 및 약관 동의 체크박스가 0.1초 만에 자동 완성
- **🛡️ 도서관 사이트 개편 대비 예외처리 및 모니터링 (`crawler_logs`)**:
  - 지자체 웹사이트 개편 시 조용히 0개가 긁히는 침묵의 실패를 방지하고 `구조 변경 감지(SCHEMA_MISMATCH)` 경고 발송
  - 새 수집이 실패해도 기존 SQLite DB의 캐시 데이터를 보존하여 서비스 중단 방지
  - 상단 상태 뱃지를 통해 3개 지자체 연동 상태를 실시간 확인 가능

---

## 3. 기술 스택

- **Frontend**: Next.js 16 (App Router), React 19, Tailwind CSS v4
- **Backend**: Python 3.11, FastAPI, Uvicorn, APScheduler, BeautifulSoup4, HTTPX
- **Database**: SQLite3 (로컬 저장소)
